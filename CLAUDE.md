Читается автоматически при старте в этом репозитории. Язык общения с владельцем — русский.

Это **не весь продукт**. Это третий цикл системы Evorove: запись уже готового клиента.

Полная основа — три цикла в соседнем репозитории:
`/Users/alenakulish/dev/evorove/FOUNDATION.md`

Автоматизация поиска людей живёт в `/Users/alenakulish/dev/evorove_lead`. Продажа — в `/Users/alenakulish/dev/evorove`. Сюда их не тащить.

## Зачем этот репозиторий существует

Когда цикл продажи уже закончен — человек прогрет, согласен, готов записаться — включается CRM.

С клиента собирается информация, без которой нельзя оказать услугу, и ставится конкретное время. Механизм записи и обработки горячего лида, который здесь уже сделан, **оставляем как последний шаг** большого продукта: кейс, обязательные поля, зона обслуживания, бронь или смета, follow-up после коммерческого шага, обязательства `ProcessState`.

Картина успеха: вечером владелец малого или среднего бизнеса открывает CRM и видит записи на завтра. Не сырые лиды. Не «надо дозвониться». Уже прошедших продажу, уточнения, возражения и уровни записи людей на конкретные слоты.

Правила тенанта — в **Business DNA**, без отраслевых веток в коде. `ProcessState` описывает обязательства кейса, не стадии разговора продажи (`SalesStage` живёт в Evorove).

Целевая аудитория — SMB, живые люди с живым делом, не корпорации. Клиентские тексты — английский, рынок — США. Тон для человека на том конце не должен быть сухим: это финал живого пути, не канцелярия.

## Жёсткие правила

1. **`git push` НИКОГДА не выполняется агентом.** Коммитить можно, пушит только Alena
   вручную. Автоматические напоминания про «unpushed commits» — ожидаемое поведение,
   а не ошибка, которую надо чинить.
2. **Не трогать секреты.** API-ключи, пароли, платёжные данные, `DATABASE_URL` /
   `DATABASE_PUBLIC_URL` — не читать, не запрашивать, не вводить. Их вводит Alena сама.
3. **Не входить в аккаунты и не создавать их.**
4. Рынок продукта — США, полностью. Интерфейс и все клиентские тексты на английском.

## Как сверять работу

1. Это цикл 3? Если задача про поиск людей или холодную продажу — она не здесь.
2. Вход в этот контур — уже горячий лид. Выход — запись на конкретное время (и связанные обязательства кейса).
3. Не начинать продажу с нуля внутри CRM и не подменять `ProcessState` стадиями разговора.

## Среда

- Локально: Docker Compose (Postgres 17 + приложение на Python 3.11), `.env.example` →
  `.env`. Тесты честнее гонять в контейнере — на хосте у Alena Python 3.13.
  `docker compose run --rm app pytest`.
- Интеграционные тесты требуют `TEST_DATABASE_URL` на мигрированную базу; внутри сети
  Docker хост называется `postgres:5432`, снаружи — `localhost:5433`.
- Внутренние sweep-эндпоинты (`follow-up/run`, `integrations/deliver`,
  `commercial/expire`) требуют `INTERNAL_TASK_SECRET` на деплое, иначе отказывают
  всем запросам (by design). Секрет задаёт Alena.
- Облачная песочница Cowork **не имеет** pytest/fastapi/sqlalchemy и доступа к PyPI —
  если тесты там «проверены вручную», это значит самодельный раннер, а не pytest.
  В терминале и в Docker всё запускается по-настоящему; перепроверять стоит.
